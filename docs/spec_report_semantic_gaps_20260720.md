## 2. 原子验收条目

### RSG-01 固定基因/结构域知识不得被静默丢弃

- 从基础知识库提取固定蛋白和结构域描述，不能因 reviewed `domain_text` 是否存在而直接丢弃。
- 基础简介、基因级 overlay、位点级 overlay 组合后，固定结构域信息仍必须出现。
- 多来源结构域内容应合并互补信息，并避免完全重复的句子或结构域条目。
- ERBB2 精确位点回归必须保留 1255 aa 固定结构域段。
- KRAS 回归必须同时保留 RAS 结构域和 Hypervariable region，且各出现一次。

### RSG-02 缺库基因必须显式治理

- FANCA、PALB2、DNMT3A、RAD51D 不得以 22/23 字占位简介冒充结构域知识完整。
- 新增内容必须具有来源、审核状态和适用范围；本轮状态只能是 `provisional_runtime`/待报告组二审。
- 缺少正式内容时，知识门禁必须报告缺口，不能静默 PASS。

### RSG-03 药物表与第三部分解析一致

- 同一精确变异的重叠药物集合不得生成重复解析块。
- 对已经迁移为 reviewed 精确/基因级药物契约的条目，2.1 表格中每个非空获益/慎用药物，第三部分必须存在对应解析，或存在结构化、可追溯的抑制原因。
- 旧基础库中尚未迁移为明确变异契约的泛化药物叙述不纳入本轮阻断范围；不得据此宣称全部历史药物知识已完成精确迁移。
- KRAS G12D、PALB2 精确移码、RAD51D 精确无义变异作为本轮正例。
- 不得把基因级 HRR 文献扩大到该基因任意变异或任意癌种。

### RSG-04 指南表Ⅲ类标记

- NCCN 结果表中的Ⅲ类变异须追加统一文案 `（意义未明变异）`。
- Ⅰ/Ⅱ类不得被追加该文案。

### RSG-05 靶向结果表版式

- `2. 靶向药物相关检测结果` 使用幂等的 `pageBreakBefore`，不插入独立空白分页段落。
- 对应表格扩展到正文版心宽度；列宽配置可追溯且不改变字段数或业务内容。

### RSG-06 第三部分段后与商品名格式

- 第三部分正文段后为 10 磅（200 twips）。
- 药物商品名的方括号片段整体加粗；括号外药物通用名不被连带加粗。
- Word/LibreOffice 最终刷新后仍保持上述格式。

### RSG-07 回归与发布门禁

- 单元/契约测试、CRC 面板包校验和现有历史金标门禁通过。
- 使用两个不同 CRC 病例进行文本、结构、QA 和视觉复测。
- 三个肺癌真实输入只用于跨癌种污染检查；不得作为 CRC 医学金标，不得进入 Git。
- 修复前后的每个承重断言必须记录来源和结果；生产部署只能在干净提交、双审、发布总闸和 Linux 同款视觉复验全部通过后进行。
- 已完成验证的模板上下文必须原样传给渲染器；不得在渲染入口重新构建上下文并丢失 `_require_deterministic_layout` 等私有门禁字段。
- CRC 最终验收不得启用 `REPORTGEN_FAST_TOC=1` 绕过确定性目录重建；最终 DOCX 必须具有完整 PAGEREF/书签对应关系。

### RSG-08 视觉 QA 的诚实边界

- 两份 CRC 实例必须核对目录、目标表、Ⅲ类标记、固定结构域、药物解析、基因列表分页和低内容页。
- 报告阅读说明/法律声明页若被低内容启发式命中，只能依据 Panel 配置的完整语义标记识别为预期稀疏页；空白页、不可读页或标记不完整的页面仍必须阻断，不得靠放宽全局 QA 阈值掩盖。
- macOS LibreOffice 只能作为候选预检；正式部署验收必须记录并优先使用与 iyun129 相同的 Linux LibreOffice/字体环境。

### RSG-09 2.2 七药全集与 2.1 动态去重

- CRC358 的 2.2 审核全集固定为：瑞戈非尼、贝伐珠单抗、雷莫西尤单抗、呋喹替尼、阿柏西普、阿帕替尼、盐酸安罗替尼。
- 运行时从该 7 药全集中剔除已经出现在最终 2.1 获益/慎用药物列的药物；优先使用 `*_full` 全量字段，缺失时才回退可见字段，不能因页面压缩文案漏判。
- 只能按配置中的中文名、英文名、商品名和显式别名匹配；不得按基因、靶点、适应症或近似药名推断。
- 无命中时必须展示 7 行；部分命中时展示严格差集；7 药全部命中时允许结果为空。
- 动态模式只由 CRC358 Panel 显式启用；CRC301 与其他 Panel 保持原有固定表行为。
- 规则来源锚点：报告组 `7.20-测试问题.docx`，SHA256 `d3ac4eb52993b75fce8d4ca60e67c644ef972c5e4287438930560a40d8133ff4`。
