# 子宫内膜癌29 B-track 草稿 · 人工编辑成本记录表

> 给报告团队试跑用。目的：用**真实 Excel** 试跑 B 档草稿，**实测每份要手工改多少**，
> 据此决定 B 档（半自动可编辑初稿）够用、还是要投 A-track（全自动）。
>
> ⚠️ **B 档产物是内部可编辑初稿，未自动填充区域若没人工补全会"看着正式、内容错"，
> 严禁直接交付客户。** 见模板首页红色横幅、docs/endometrial29_pilot.md。

## 怎么试跑

1. 登录网站 → 上传真实 Excel → 项目类型应自动识别为 **子宫内膜癌分子分型29基因** →
   填检测者/审核者 → 生成。
2. 对照该病人**手里的旧终版**，逐区域核对草稿、记录改动与耗时（下表）。
3. **建议跑 3 类病例**（覆盖不同改动量）。已备好可直接上传的**合成 Excel**（全去标识）
   于 `output/endometrial_试跑Excel/`（见该目录 README）：
   - 病例A（`…lz900001.xlsx`）：MSS、常见驱动（最像基线）。
   - 病例B（`…lz900002.xlsx`）：MSI-H。
   - 病例C（`…lz900003.xlsx`）：变异多、改动最大（浆液性样）。
   - 也可换报告组自己的真实 Excel 跑（格式各 panel 共用）。
   - 重新生成/改病例：`python scripts/gen_endometrial_test_excels.py --template <共用Excel> --out-dir output/endometrial_试跑Excel`

## 各区域预期（来自端到端诊断，先知道哪里大概率要改）

| 区域 | 草稿里大概什么样 | 是否要人工 |
|---|---|---|
| 抬头/基本信息（姓名/年龄/样本/诊断/日期/编号） | 已按 Excel 填 | 通常**否**，核对即可 |
| 变异/药物详情表（潜在获益靶向/免疫药物表） | 按 Excel+药物库自动填（有靶向药的变异） | 核对；无靶向药变异不显示属正常 |
| QC表 / 29基因列表 / 诊疗知识 / 信号通路 / 分子分型科普 | 静态正确 | 通常**否** |
| **MSI 结论句**（"该肿瘤样本为 X 型"） | 显示「待填写：MSI结果」占位 | **是**（必填） |
| **检测结果小结表 的变异列表行** | 显示「待人工填写」 | **是** |
| **第三部分 3.1 体细胞变异解析 叙述** | 显示「3.1…草稿未填」占位 | **是**（逐变异写） |
| **第三部分 4.1 潜在获益药物解析 叙述** | 显示「4.1…草稿未填」占位 | **是**（逐药写） |
| 变异计数（"共N个体细胞变异"） | 可能数目不对（CRC口径） | **核对/改** |
| 参考文献 | 通用 PTEN/PIK3CA/CTNNB1 文献 | 按实际变异**核对/增删** |
| 遗传性肿瘤/胚系/林奇、POLE | 阴性默认兜底 | 阳性病例**必改** |
| 检测者/审核者签名 | 按签名库 | 核对签名图 |
